One panel for everything your AIs read and write

Skills, agents, commands, rules, MCPs, plugins and configuration files — by artifact type, by AI or by project. With viewer, safe editing and audit.

By AI and by project

Pick the tool and see everything from it; or browse the repositories detected under ~/Projetos, with tree, MIME, size and author of the last commit.

Viewer and safe editing

Markdown with Mermaid, JSON, images and Monaco. Automatic backup (10 versions per file), conflict detection if the file changes outside and restore from the interface.

Usage, spend and skills

Account limits and reset, cost and tokens read from the local logs — per model, project and day — and the top 20 skills by invocations and context tokens.

MCPs, plugins and versions

Enable and disable MCPs right on the card, authenticate via OAuth and track installed vs. published version, with update and copy of the command to your terminal.

Open the AI where you need it

One click opens the CLI in the detected terminal or the native app, right in the project directory — handy to continue exactly where the panel showed you the file.

Conversation history

Track complete session history per AI or project, with token usage, estimated dollar costs, message counts, Top 20 filters, and direct terminal resumption.

Global search, shortcuts & theme

Search with ⌘F and line highlighting, global keyboard shortcuts to collapse/expand (⌘A), light/dark theme (⌘T), refresh (⌘R), sidebar (⌘B), and language (⌘L).

Real-time statusline

Terminal statusline with token quotas (5h, 7d), context window, accumulated spend, and Git diff for Claude Code and Antigravity. Interactive installer, web preview, and automated backup restoration.

Conversation history and intelligence

Monitor your AI sessions in real time: tokens consumed, calculated cost per session, Top 20 rankings, project folder grouping, and instant CLI resumption in one click.

Prominent top-line metrics

Each session displays the AI badge, estimated USD cost, total tokens, and message count right on line 1, keeping titles clean and clear.

Top 20 Spend & Top 20 Tokens

Instantly identify the sessions that consumed the most budget or context tokens, with dedicated filters and rankings.

Folder grouping & smart collapse

Sessions grouped automatically by project directory, with one-key shortcut to collapse or expand all folders at once (⌘A).

Markdown preview & CLI resume

Expand conversation messages in rich Markdown and copy or execute the native resumption command (--resume) in your terminal.

Running in a minute

The backend serves the frontend build at 127.0.0.1:4747. For development with hot reload, run Vite in parallel (just dev).

macOS uv 0.8+ Python 3.14 Node 22+ pnpm 10+ just (optional) Podman (optional)
terminal
gh repo clone mvvitorsilvati/ai-manager-local
cd ai-manager-local

just setup      # deps: uv sync + pnpm install
just start      # frontend build + up at 4747
just statusline # install statusline (Claude/Antigravity)

Without just: cd backend && uv sync, cd web && pnpm install && pnpm build and then uv run --project backend backend/app.py.

Usage cards only appear with the AI authenticated locally — you log in from the tool itself.

Limits

The panel shows what the tools leave on disk. What they do not record, it does not invent.

Extras only on macOS

Opening in the native app, app icons, Finder and Keychain are macOS-only. Outside it the Finder button is disabled with a warning, and opening in the installed terminals is what remains.

Skills by invocation

Claude Code, opencode, and Antigravity keep that history in local logs. On Codex and Copilot the screen lists the skills that exist on disk, without usage counts.

Spend is an estimate

Cost and tokens come from the logs at list prices, not from your bill. Copilot shows up in AIU, not dollars.

AIs on Windows, panel on WSL

Point AIM_HOME to /mnt/c/Users/<you> to read the Windows side settings. Windows Terminal is not included in the terminal list.

Local for real

The panel was made to inspect sensitive files: AI settings, rules and credentials that live on your machine. That is why it sends nothing anywhere.

127.0.0.1 only

Nothing exposed on the network by default; the host only changes in a container, by explicit choice.

No telemetry

Backups and audit live in ~/.ai_management_local — on your disk, under your control.

External only to show your data

Calls out go only to the official APIs: account limits and usage, versions published on npm and the status pages — with the credentials that already exist on the machine.
